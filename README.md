# NEO JAPAN CLASH（仮）

和×電脳のオンライン格闘ゲーム。横画面・PSP式の画面パッドで遊ぶ。

## 遊び方
- ブラウザで開くだけ（公開版）: https://richend0913.github.io/neo-japan-clash/
- アーケード：CPUと5連戦。クリア条件で隠しキャラが解放される（初期10体＋解放4体）
- フリーバトル：好きなキャラ・難易度で1試合
- 左下が十字キー、右下が丸ボタン4つ（○弱／×強／□必殺／△ガード）、上端が L / R（ダッシュ）
- PCは矢印キー＋J/K/L/U、Q/Eでも操作できる

## オンライン対戦（2〜4人・勝ち抜き）
公開版では準備中。手元の環境ではサーバーを起動すると遊べる：

```
npm install
node server.js   # http://127.0.0.1:8902/
```

ルームを作る（4桁コード発行）か、コードで参加。1対1で戦い、待機中は観戦、負けると観戦者と入れ替わる。

## 構成
- `index.html` / `style.css` / `js/` — ゲーム本体（外部素材なし、オフライン可）
- `server.js` — 静的配信＋WebSocket中継（依存は ws のみ）
- `test/` — シミュレーション／WS／実ブラウザの確認スクリプト
- 詳細は `BUILD_NOTES.md`
